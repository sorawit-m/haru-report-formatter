# แบบฟอร์มสรุปท้ายงาน (ตอบผู้ใช้เป็นภาษาไทย)

เปิดด้วยประโยคเดียวว่าเล่มไหนเสร็จแล้ว อยู่ที่ไหน (.docx + .pdf) และต้นฉบับสำรองอยู่ที่ไหน

## ผลต่อเล่ม
| เล่ม | หน้า (ก่อน → หลัง) | สถานะ |
|---|---|---|
| <ชื่อเล่ม> | 85 → 79 | ไล่ดูทุกหน้าแล้ว / ยังมีจุดต้องดู |

## สิ่งที่แก้ (นับจำนวน)
| รายการ | เล่ม A | เล่ม B |
|---|---|---|
| ตารางข้ามหน้าไม่มีหัว (ก่อน → หลัง) | 39 → 0 | |
| ตารางหัว/เนื้อหาที่แยกกัน รวมเป็นตารางเดียว | | |
| ตัวอักษรถ่าง (line break / เซลล์จัดกระจาย) | | |
| ฟอนต์ปน → ฟอนต์เดียว | | |
| เส้นตาราง จาง/หาย → ดำ 0.5 pt | | |
| หน้าว่างที่ลบ | | |
| ย่อหน้าซ้ำที่ลบ | | |
| คำผิด/เว้นวรรคที่แก้ | | |

## สีแดงที่ยังอยู่ในเล่ม (คงไว้ ไม่เปลี่ยนสี)
- <เล่ม> หน้า <n> (หน้า PDF <m>) <ตำแหน่ง เช่น ตาราง UC-010 ช่อง Post-condition>: "<ข้อความ>"

## เนื้อหาที่แก้ให้ (เฉพาะโหมด "แก้ทุกจุด")
**<เล่ม>**
- หน้า <n>: "<ข้อความเดิม>" → "<ข้อความใหม่>" — <เหตุผล/หลักฐาน เช่น ตรงกับตาราง 3.2 หน้า 18>

## จุดแปลก ๆ ที่ยังไม่ได้แก้ (ต้องให้คนตัดสิน)
**<เล่ม>**
1. <ตำแหน่ง>: <อาการ> — <ทำไมไม่แก้ / ควรทำอะไร>
(ใส่เลขข้อ เพื่อให้ผู้ใช้สั่ง "แก้ข้อ 1, 3" ได้)

โหมดปกติ ปิดท้ายด้วย: ถ้าอยากให้แก้จุดเหล่านี้ด้วย พิมพ์ "แก้ทุกจุด" หรือ "แก้ข้อ ..." ได้เลย

## สิ่งที่ยังตรวจไม่ได้
- เช่น บน Mac ตรวจหน้าว่าง/ตารางสูงเกินหน้าแบบอัตโนมัติไม่ได้ → ให้เปิดหน้า <...> ใน Word เช็ก

ใช้ตาราง/หัวข้อเฉพาะเมื่อช่วยให้อ่านง่าย ข้อความสั้น ตรงประเด็น ไม่ใช้ศัพท์เทคนิคโดยไม่จำเป็น
