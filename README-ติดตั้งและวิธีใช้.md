# Skill "จัดเล่ม" (report-formatter) — ติดตั้งและวิธีใช้

ตรวจและจัดรูปแบบเล่มรายงาน Word (.docx) ให้สวยและถูกต้อง แล้วได้ PDF พร้อมสรุปเป็นภาษาไทย
พิมพ์แค่ **จัดเล่ม** แล้วแนบไฟล์ ที่เหลือทำให้เอง

## 1) ติดตั้ง (ทำครั้งเดียวต่อบัญชี)
1. เข้า **claude.ai** ด้วยบัญชีของทีม
2. ไปที่ **Settings → Capabilities** (บางเวอร์ชันชื่อ Customize) → หัวข้อ **Skills**
3. กด **Upload skill** แล้วเลือกไฟล์ `report-formatter.zip`
4. เปิดสวิตช์ให้ Skill ทำงาน (ถ้ามี)

ทุกคนที่ล็อกอินบัญชีนี้ ทุกเครื่อง จะเห็น Skill นี้เลย ไม่ต้องติดตั้งทีละเครื่อง
ถ้าแก้ Skill ภายหลัง ให้อัปโหลด .zip ใหม่ทับ

## 2) เครื่องที่ใช้ต้องมี
| เครื่อง | ต้องมี | ได้ผล |
|---|---|---|
| **Windows** (แนะนำ) | Microsoft Word, Node.js (ฟรี: nodejs.org), ฟอนต์ TH SarabunPSK | ครบทุกข้อ |
| **Mac** | Word for Mac, Node.js, Xcode Command Line Tools (`bash install.sh` ติดตั้งให้เอง), ฟอนต์ TH SarabunPSK (มากับ Word) | ครบทุกข้อเท่า Windows ; ไม่มี Word ใช้ LibreOffice ได้ ~90% |

ต้องใช้ผ่าน **แอป Claude แท็บ Code** (หรือ Claude Code) ที่เปิดไฟล์ในเครื่องได้ ใช้ในแชตบนเว็บธรรมดาไม่ได้ เพราะต้องสั่ง Word ในเครื่อง

## 3) วิธีใช้
พิมพ์ในแท็บ Code:

```
จัดเล่ม
```
แล้วแนบไฟล์ (ลากไฟล์มาวาง หรือพิมพ์ @ แล้วเลือกไฟล์) ใส่ได้หลายไฟล์พร้อมกัน
หรือสั่งทั้งโฟลเดอร์: `จัดเล่ม โฟลเดอร์ D:\งานส่งมอบ` (หรือเปิด session บนโฟลเดอร์นั้นแล้วพิมพ์ `จัดเล่ม` เฉย ๆ) จะทำทุกไฟล์ .docx ในโฟลเดอร์ทีละเล่ม

ตัวอย่างที่สั่งเพิ่มได้:
- `จัดเล่ม แก้ทุกจุด` → แก้เนื้อหาที่ขัดกัน/ไม่ชัดให้ด้วย (ดูข้อ 4.1)
- หลังได้สรุปแล้ว พิมพ์ `แก้ทุกจุด` หรือ `แก้ข้อ 2, 5` → แก้เฉพาะข้อที่สั่งแล้วทำเล่มใหม่ให้
- `จัดเล่ม ไม่ต้องทับไฟล์เดิม` → บันทึกเป็นไฟล์ใหม่ต่อท้าย `_จัดรูปแบบ`
- `จัดเล่ม บทที่ 2 ไม่มีเนื้อหา เอาออก` → ตัดบทแล้วเลื่อนเลขบท/หัวข้อให้
- `จัดเล่ม ใช้ฟอนต์ TH Sarabun New ขนาด 14`
- `จัดเล่ม ทำเป็น PDF ด้วย` (ปกติได้ PDF อยู่แล้ว)

## 4) ได้อะไรกลับมา
- ไฟล์ .docx ที่แก้แล้ว (ทับไฟล์เดิม ต้นฉบับสำรองไว้ใน `สำรองต้นฉบับ_ก่อนจัดรูปแบบ`) และ .pdf ชื่อเดียวกัน
- สรุปภาษาไทย: แก้อะไรไปบ้าง, **สีแดงอยู่หน้าไหน** (คงไว้ไม่เปลี่ยน), **จุดที่ต้องให้คนตัดสินใจ** เช่น ตัวเลขไม่ตรงกัน หัวข้อไม่มีเนื้อหา

### 4.1) โหมด "แก้ทุกจุด"
ปกติเรื่องเนื้อหาที่ขัดกันจะแค่แจ้ง ถ้าอยากให้แก้ด้วย พิมพ์ `จัดเล่ม แก้ทุกจุด` (หรือ `แก้หมด`, `แก้เนื้อหาด้วย`)
- ตัวเลข/ชื่อที่ขัดกัน → ใช้ค่าจากตารางรายละเอียดหรือเล่มที่เป็นแหล่งหลัก (เช่น Endpoint ยึดเล่ม API)
- ชื่อเรียกไม่เหมือนกัน → ใช้แบบที่ใช้มากที่สุด
- ประโยคอ่านไม่เข้าใจ/ภาษาพูด → เรียบเรียงใหม่ ความหมายเดิม
- บท/หัวข้อไม่มีเนื้อหา → ลบ แล้วเลื่อนเลขให้
- เลขรูป/ตารางข้ามหรือซ้ำ → เรียงใหม่
- บทสรุปไม่ตรงรายละเอียด → แก้บทสรุปให้ตรง
- **ยังไม่แตะ:** ข้อความสีแดง, โค้ด/SQL/JSON, ข้อมูลที่ไม่มีหลักฐานในเอกสาร (จะแจ้งพร้อมเหตุผล)
- ทุกจุดที่แก้เนื้อหาจะอยู่ในสรุป: หน้า / เดิม → ใหม่ / เหตุผล และมีต้นฉบับสำรองเสมอ

## 5) สิ่งที่ Skill แก้ให้
ฟอนต์เดียวทั้งเล่ม · เนื้อหา/bullet/ตาราง จัดกระจายแบบไทย · หัวตารางซ้ำทุกหน้า · รวมตารางหัว/เนื้อหาที่แยกกัน · ขอบตารางเท่ากันทุกแถว · เส้นตารางชัด · ตัวอักษรไม่ถ่าง ·
บทขึ้นหน้าใหม่ · หัวข้ออยู่หน้าเดียวกับรูป/ตาราง · ลบหน้าว่าง · สารบัญ/สารบัญรูป/ตารางอัปเดต · คำผิด/เว้นวรรค · ไม่มีตัวเอียง ·
ไฟล์ Word ยังแก้ต่อได้ปกติ (พิมพ์แล้วหน้าไม่เด้ง) · ประโยคติดกันในตาราง (Shift+Enter / ย่อหน้าขาด → รวม) ·
ป้ายภาษาไทยให้ Word บน Mac ตัดคำไม่ขาดกลางคำ · ลบบรรทัดว่างคั่นข้อที่มีเลข · ไม่มีช่องว่างครึ่งหน้า ·
ตรวจอัตโนมัติว่าเลขหัวข้อตรงต้นฉบับทุกย่อหน้า และหาหน้าที่ว่างผิดปกติ

## 6) ข้อควรรู้
- **ปิดไฟล์ใน Word ก่อนสั่ง:** ถ้าเปิดอยู่ จะแก้ไฟล์ไม่ได้
- **เวลาที่ใช้:** เล่ม ~50 หน้าประมาณ 2–5 นาที, ~350 หน้าประมาณ 20 นาที, 500–800 หน้าประมาณ 25–30 นาที ทำได้ทีละเล่ม เพราะใช้ Word ตัวเดียว
- **Word ค้าง หรือขึ้น error ว่าเปิดไม่ได้:** เปิด Word เองหนึ่งครั้ง ถ้ามีกล่อง "กู้คืนเอกสาร" ให้เลือก "ไม่ ให้เอาไฟล์เหล่านี้ออก" แล้วสั่งใหม่
- **เนื้อหาที่ขัดกัน:** ปกติแค่รายงาน ถ้าอยากให้แก้ พิมพ์ `แก้ทุกจุด` (ข้อ 4.1)
- **ปรับค่ามาตรฐาน:** ถ้าอยากเปลี่ยนค่าเริ่มต้น (ฟอนต์, ความหนาเส้น ฯลฯ) ให้แก้ใน `config.json` แล้วอัปโหลด .zip ใหม่
